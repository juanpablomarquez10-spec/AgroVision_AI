AgroVision_AI 🌱

Sistema de detección de enfermedades en hojas de tomate mediante Deep Learning

1. Descripción del proyecto

AgroVision_AI es un proyecto académico que busca desarrollar un sistema de inteligencia artificial capaz de identificar enfermedades en hojas de tomate a partir de imágenes, utilizando técnicas de Deep Learning y visión por computadora.

2. Problema

Las enfermedades en los cultivos de tomate pueden afectar su productividad y calidad. La identificación temprana de síntomas mediante imágenes puede contribuir a facilitar su detección.

3. Objetivo general

Desarrollar un modelo de Deep Learning que permita clasificar imágenes de hojas de tomate según la enfermedad identificada.

4. Datos

El proyecto utiliza un conjunto de imágenes de hojas de tomate organizado en carpetas por categorías de enfermedades.

Categorías consideradas:

Tomato___Bacterial_spot

Tomato___Early_blight

Tomato___Late_blight

Tomato___Leaf_Mold

Tomato___Septoria_leaf_spot

Tomato___Tomato_Yellow_Leaf_Curl_Virus
