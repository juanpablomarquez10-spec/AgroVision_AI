🌱 AgroVision_AI

Sistema de detección de enfermedades en hojas de tomate mediante Deep Learning

1. Descripción del proyecto

AgroVision_AI es un proyecto académico que busca desarrollar un sistema de inteligencia artificial capaz de identificar enfermedades en hojas de tomate a partir de imágenes, utilizando técnicas de Deep Learning y visión por computadora.

2. Planteamiento del problema

Las enfermedades en los cultivos de tomate pueden afectar su productividad y calidad. La identificación temprana de síntomas mediante imágenes puede contribuir a facilitar su detección y apoyar la toma de decisiones en el sector agrícola.

3. Objetivo general

Desarrollar un modelo de Deep Learning que permita clasificar imágenes de hojas de tomate según la categoría correspondiente.

4. Conjunto de datos

El proyecto utiliza un conjunto de imágenes de hojas de tomate organizadas en carpetas según las categorías disponibles.

Categorías identificadas durante la revisión inicial:

Tomato___Bacterial_spot

Tomato___Early_blight

Tomato___Late_blight

Tomato___Leaf_Mold

Tomato___Septoria_leaf_spot

Tomato___Tomato_Yellow_Leaf_Curl_Virus

5. Tecnologías utilizadas

Python: desarrollo de los scripts del proyecto.

Deep Learning: entrenamiento de modelos de clasificación de imágenes.

Procesamiento de imágenes: preparación de los datos visuales.

Git y GitHub: control de versiones y almacenamiento del código.

6. Estado actual del proyecto

El proyecto se encuentra en la etapa de preparación y verificación de los datos. Posteriormente, se trabajará en la división del conjunto de imágenes, el entrenamiento de modelos y la evaluación de sus resultados.
